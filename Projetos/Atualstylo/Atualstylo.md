# Atualstylo - Dashboard do Projeto

Documentação de acompanhamento e ideias para a evolução do projeto da barbearia **Atualstylo**.

## Tarefas Principais

1. **Mudar o Admin de Denilsson**
   - Verificar e alterar a situação do admin, pois não está bloqueado por mais de uma semana.
   - Verificar como esta sendo apagado os bloqueios. Provavelmente esta indo de um por um.

2. **Modificar a navegação**
   - Melhorar a fluidez e a usabilidade da navegação entre as páginas do site.

3. **Mudar o sistema de cancelamento**
   - Ajustar para que o sistema pegue o número automaticamente assim que o usuário clicar no link de cancelamento.

## Ideias Futuras e Escalabilidade

4. **Sistema de Contas para o Site**
   - Criar um sistema de contas/cadastro de forma que os clientes possam se registrar mais facilmente para agendamentos e interações.

5. **Loja de Produtos**
   - Analisar a viabilidade técnica de incluir uma seção de loja no site, com o objetivo de vender produtos de afiliado.
